Official Rules

狼人殺社內規則

本社團標準發言時長、警長競選與歸票、狼人自爆、死後與白天技能發動規範，以及加速局拍刀判定流程。

角色規則

角色技能與判定跟隨 Line 官方帳號：狼人殺大百科

遊戲進行

# 發言規則

每人每輪發言時長為 90 秒，每人每局有 兩次機會加時 30 秒。

# 警長規則

第一天白天公布死訊前，進行警長競選，所有玩家皆可選擇上警，警上玩家可隨時退水（也可在發言結束後的退水環節退水），警下玩家可對警上玩家投票（退水玩家視為無法投票），若僅剩一人在警上則自動當選警長，否則高票者當選，若存在平票，則需進行 PK 發言，PK 台下玩家皆可對 PK 台上玩家投票，最高票者當選，否則警徽流失，若所有玩家上警，僅能以退水到剩一人的方式獲得警徽。

當選警長者可獲得 1.5 票歸票權，在單死當天，警長可選擇從死左或死右開始發言，否則以警左或警右開始發言，在所有人發言完畢後，警長可以歸票，若歸票一人，警長可維持 1.5 票，否則變為 1 票。

# 自爆規則

若拿到的狼人牌可自爆，可在警長階段以及白天階段的任意時間自爆，直接進入天黑，無須翻牌且沒有遺言，自爆的狼人可選擇在夜晚點刀後離場，若警上階段被女巫灑毒的狼人自爆仍可自爆成功，若狼人在警上階段自爆，天亮後直接進入退水環節，若此時又有狼人自爆，則警徽流失（稱為雙爆吞警徽）。

# 日間技能規則

死後發動技能的角色（如：獵人）要發動技能需自行告知上帝，上帝不會主動提醒。

白天發言階段的技能依角色技能發動時機發動（如：騎士可在白天發言階段隨時發動技能）。

# 拍刀規則

拍刀可視為加速版爆刀，夜晚見面的狼人可在白天或夜晚狼人階段隨時提出拍刀，若白天階段僅一位狼人選擇拍刀，且該玩家可以自爆，則視為該玩家自爆。拍刀提出後，見面的狼人可直接討論，若有不見面的狼人在場，需先點出其號碼才能參與討論。

拍刀時，神職技能視為全數發動正確（如：守衛全守中、女巫必毒狼等），計算最終刀數，若最終刀數不足，則好人勝利，若刀數充足，則狼人討論刀型並選擇最終號碼，若選中之號碼可達成勝利條件且好人無其他輪次技能可用，則狼人勝利。

暴民 陣營標籤

鏈子 / 進鏈 特殊身分

好人鏈 / 狼狼鏈 特殊身分

狼狼鏈：情侶雙方都是狼人。

人狼鏈 / 髒鏈子 特殊身分

情侶雙方為一個好人與一個狼人，丘比特版型中會形成第三方獨立陣營。

首置位 / 末置位 發言順位

首置位：一輪中第一個發言的玩家。
末置位/沉底位/歸票位：一輪中最後一個發言的玩家。

前置位 / 後置位 發言順位

前置位/高置位：發言靠前或在某人之前發言的玩家。
後置位：發言靠後或在某人之後發言的玩家。

警上 / 警下 場態空間

警上：參與警長競選的玩家。
警下：未參與警長競選的玩家。

焦點位 / 外置位 場態空間

焦點位：當前討論度、可疑程度較高的玩家。
外置位：當前非焦點位、未被定義身分的玩家。

原始起跳位 場態空間

最初被狼隊安排悍跳，但實際未起跳的狼人。

表水 / 划水 發言手法

表水：清晰表達自己的邏輯和行為原因，盡力說清身份以洗脫嫌疑。
划水：發言沒有提供任何有價值的資訊或觀點。

聊爆 / 跟風 發言手法

聊爆：狼人在發言中無意暴露了自己的身份。
跟風：玩家發言時單純模仿之前玩家的觀點。

踩 / 丟水包 發言手法

踩：指出其他玩家發言問題或認為其身分不好。
丟水包：發言時主動向懷疑對象施加壓力的行為。

遞話 / 洗頭 發言手法

遞話：暗中向場上特定玩家傳遞資訊的行為。
洗頭：洗腦，以強邏輯或話術說服其他玩家站邊。

心路歷程 / 言行合一 發言手法

心路歷程：詳細交代做決策思維演變過程。
言行合一：白天發言立場與實際投票行為完全吻合。

篡改發言 / 更新發言 發言手法

篡改發言：故意歪曲或誇大他人原話以做低其身分。
更新發言：進入新一輪時的最新發言內容。

好人面 / 匪面 / 爆點 身分評估

好人面：像好人的特徵。
匪面/狼面/爆點：指發言或行為中像狼人或聊爆的地方。

做高 / 做低 / 做好 身分評估

做高：讓某玩家身分更像好人。
做低：讓其身分更像狼人。
做好：指該玩家極高機率是好人或行為極有誠意。

聽感 / 聽殺 / 聽保 身分評估

聽感：發言聽起來的邏輯正度與情緒狀態。
聽殺：聽起來肯定是狼人。
聽保/聽正：聽起來肯定是好人。

正邏輯 / 反邏輯 邏輯與視角

正邏輯（第一層）：最直覺、表面的邏輯。
反邏輯（第二層）：較深層、反套路與非直覺的邏輯。

鐵邏輯 / 偽邏輯 邏輯與視角

鐵邏輯：絕對成立、無可辯駁的正確邏輯。
偽邏輯：站不住腳、存在漏洞或不一定正確的推論。

狼坑 / 點狼 / 開匪 邏輯與視角

狼坑：主觀推算出的所有狼人席位。
點狼：指出認為是狼人的玩家。
開匪/開狼：指某些特定玩家之中存在狼人。

賣視角 / 賣白 邏輯與視角

賣視角：發言無意透露了只有特定身分才會知曉的夜間資訊。
賣白：發言中賣出了某人為白牌（自己未知）的視角。

抿牌 / 盤雙邊 / 容錯 邏輯與視角

抿牌：透過神情或微動作推測身分。
盤雙邊：同時站在兩位預言家角度盤其狼坑。
容錯：誤判可能，或好人能承受的失誤刀數空間。

起跳 / 對跳 / 悍跳 起跳策略

起跳：聲稱自己是某個角色。
對跳：多名玩家聲稱同一神職。
悍跳：狼人冒充神職身分。

羅悍跳 / 搏殺 起跳策略

羅悍跳：多個狼人共同冒充同一個神職。
搏殺：狼人悍跳給後置位疑似真預言家的玩家發查殺。

穿衣服 / 脫衣服 偽裝策略

穿衣服：宣稱自己是某個非真實身分。
脫衣服：主動承認並放棄之前聲稱的虛假身分。

詐身份 / 原地起跳 策略博弈

詐身份：透過虛假發言獲取別人的真實反應。
原地起跳：警上接到查殺後立即起跳預言家。

代跳 / 擋刀 / 拉杆 戰術策略

代跳/擋刀：民冒充神職吸引狼刀。
拉杆：狼人悍跳通靈師時直接報出其他好人真實具體身分。

站邊 / 衝鋒 / 倒鉤 團隊博弈

站邊：選擇相信其中一位預言家。
衝鋒：站邊悍跳狼的狼人。
倒鉤：站邊真預言家的狼人。

陰陽倒鉤 / 墊飛 高級戰術

狼人站邊真預言家但故意發言極差（通常悍跳神職），讓好人誤以為他是衝鋒狼，進而站錯邊做低真預言家。

旋風倒鉤 / 螺旋墊飛 高級戰術

狼人站邊悍跳狼，但發言故意讓場上以為是在打陰陽倒鉤/墊飛，藉此誘使好人反而站邊悍跳狼。

狼踩狼 / 騙藥 團隊配合

狼踩狼：狼隊友互打做高彼此身分。
騙藥：使用自刀等套路讓女巫交出解藥。

打板子 / 安排工作 / 壓榨 團隊操作

打板子：配合操作。
安排工作：規範夜間神職技能目標。
壓榨身份：壓縮空間迫使玩家拍身分。

反水 / 反水立警 身分宣告

反水：不承認給自己發金水的預言家身分。
反水立警：接金水後直接起跳預言家競選警長。

認出 / 認狼 / 孤狼宣言 身分宣告

認出：同意放逐自己。
認狼：直接宣稱是狼。
孤狼宣言：最後一狼明牌提示第三方在場以求生存。

正視角 身分宣告

真假預言家難辨時，有資訊的神職主動起跳明晰局勢。

警徽流 警徽機制

預言家交代後續驗人順序，透過決定發言順序或死後移交警徽傳遞查驗資訊。

退水流 / 退狼流 / 前剛後放 退水策略

退水流：聽信預言家後退水。
退狼流：聽出狼人後退水。
前剛後放：信先跳的不退水，信後跳的則退水。

撕警徽 / 吞警徽 警徽機制

撕警徽：出局不移交警徽使其流失，或公投出局警長。
吞警徽：狼人警上自爆（通常雙爆）導致警徽流失。

歸票 / 號票 / 衝票 投票機制

歸票：警長末置位號召投票。
號票：號召大家齊投某人。
衝票：多名狼人合力綁票投出某人。

分票 / 壓手 (棄票) 投票機制

分票：票型分散未跟隨歸票。
壓手/棄票：放逐環節選擇棄權不舉手投票。

平票 PK / 拉 PK 投票機制

平票PK：同票玩家額外進行一輪對決發言。
拉PK：號召票型投成平票對決。

票型 / 票出 / 順抬 投票機制

票型：各玩家投票分佈情況。
票出：高票放逐出局。
順抬/順推：按既定順序依序公投出局。

外飛 / 扛推 / 扛出 投票機制

外飛：票出查驗與警徽流之外的玩家。
扛推：好人被公投放逐。
扛出：無明確目標時放逐不影響輪次者。

驗一砸一 投票機制

在兩名可疑程度類似的玩家中，查驗一人同時放逐另一人。

帶走 / 刀口 / 倒牌 結算狀態

帶走：技能使人出局。
刀口：夜間被狼擊殺者。
倒牌：出局。

平安夜 / 平安日 結算狀態

平安夜：前一晚無人倒牌。
平安日：白天無人被放逐出局。

空守 / 自守 / 奶穿 好人技能

空守/自守：守衛不守或守自己。
奶穿（同守同救）：同晚守衛守護且女巫用解藥，導致目標出局。

斷劍 / 撒毒 / 撈 好人技能

斷劍：騎士決鬥好人自己死。
撒毒/潑：女巫使用毒藥。
撈：女巫使用解藥救人。

盲毒 (天毒) / 彈死 / 自證 好人技能

盲毒/天毒：女巫首夜盲毒。
彈死：商人給狼幸運兒自己死。
自證：用技能證明真實身分。

空刀 / 首刀 / 自刀 / 自爆 狼人技能

空刀/首刀：狼隊不殺或首夜刀人。
自刀：狼夜間刀自己騙藥。
自爆：白天中斷發言直接進黑夜。

入狼隊 / 反傷 / 連 / 埋 特殊技能

入/不入狼隊：夜間是否參與討論。
反傷：惡靈反彈。
連：丘比特連情侶。
埋：盜賊捨棄底牌。

輪次 / 刀推領先 勝負判定

輪次：殺戮與推人步調。
狼刀領先：狼先屠邊完成。
警推領先：好人先放逐全部狼人。

狼刀在先 / 綁票 / 交牌 勝負判定

狼刀在先：狼刀優先結算，達標即勝。
綁票：狼票過半勝負已分。
交牌：認輸放棄對局。

屠邊 / 屠城 / 屠神 / 屠民 獲勝方式

屠邊：殺光所有神職或所有平民之一即勝。
屠城：殺光所有好人。
屠神/屠民：殺光特定單邊身分。

慫狼局 / 單邊預 局況模式

慫狼局：沒有狼人悍跳預言家的對局。
單邊預：全場僅有一人聲稱是預言家。

生推局 / 團隊 局況模式

生推局：資訊過少、純靠發言推盤的局。
團隊：具有相同目的或站邊立場的群體。

場外 / 貼臉 競技邊界

場外：非遊戲進行中的內容（如看掛相、聽聲響）。
貼臉：情緒化發言、發誓賭咒等破壞競技禮儀的行為。
